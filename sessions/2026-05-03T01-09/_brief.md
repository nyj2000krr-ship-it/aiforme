# 📋 작업 브리프

**원 명령:** 지식은 로컬 어느 위치에 저장되어 잇어?

## 요약
사용자가 회사 지식의 로컬 저장 위치에 대해 질문했으므로, 기술적인 저장 구조를 분석하고 이를 사용자 친화적인 형태로 요약하여 전달해야 합니다.

## 분배
- **💻 Developer**: 현재 회사 지식 및 대화 로그의 저장 구조(파일 경로, 데이터 형식, 동기화 방식)를 분석하고, 사용자에게 설명할 수 있도록 기술적 보고서를 작성해주세요. 특히 'CEO 개인 메모리', '회사 의사결정 로그', '회사 대화록'의 저장 위치와 특성을 명확히 구분해야 합니다.
- **📱 Secretary**: Developer가 제공한 기술적 보고서를 바탕으로, 비기술적인 사용자 입장에서 이해하기 쉽고 친절하며, 필요한 경우 사용자가 직접 접근하거나 관리할 수 있는 방식으로 요약된 최종 답변을 작성해주세요. 답변에는 지식이 누적되는 원칙도 포함되어야 합니다.
