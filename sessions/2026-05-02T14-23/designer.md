## 2. 메인 타이포그래피 (Main Typography)

가독성이 최우선이며, 디지털 환경(모바일)에서 부드럽게 읽히는 폰트를 선정합니다.

*   **메인 폰트:** **Pretendard** (프리텐다드)
    *   *선정 이유:* 모바일 환경에 최적화된 산세리프 계열 폰트로, 가독성이 높으면서도 지나치게 딱딱하지 않고 현대적인 감각을 유지합니다.
*   **사용 원칙:**
    *   **헤드라인 (Headline):** Pretendard Bold / 28pt ~ 36pt (강조색 배경 사용 시)
    *   **소제목 (Sub-Headline):** Pretendard SemiBold / 18pt ~ 24pt
    *   **본문 (Body Text):** Pretendard Regular / 14pt ~ 16pt
    *   **강조 키워드 (Highlight):** Pretendard Bold / 16pt (강조색 배경 처리)
